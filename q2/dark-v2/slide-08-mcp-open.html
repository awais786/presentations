MCP is the open standard that lets AI assistants call real tools. All three servers were built publicly, so client delivery and community tooling come from the same repos.

outline
From Scratch
Server built from scratch on FastMCP v3. Transports, auth relay, and packaging are ours; per-tool Outline API wrappers ported from an MIT project with attribution. 37 tools.

plane
Extended
Plane's official MCP server, extended in a public fork. Auth, workspace injection, and tool visibility were added in a cleanly isolated module. 100+ tools, 46 curated live.

118 → 8 Meta-tool layer for context scaling. A growing tool count does not fit in AI model context windows, whether GPT, Claude, or open source models. We built a discovery layer where only meta tools (list / enable / execute) are visible on connect, shrinking 118 tool schemas to ~8, with everything else activated on demand.
